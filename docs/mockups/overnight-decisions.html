Decision 2: Apps Script Top Banner vs. GitHub Pages
2A · CHOSEN

Keep Apps Script Web App (/exec)

Zero dual-hosting complexity; instant clasp deploy; no CORS/JSONP auth issues. Leaves the thin ~28px Google banner at the very top.

2B · ALTERNATIVE

Static GitHub Pages Frontend

Removes the Google banner completely, but requires converting every RPC call to fetch/CORS and maintaining two separate deploys.

Decision 3: Settings Layout + Doctor Phone
3A · CHOSEN

New Section Below Current Settings

Adds a 3rd section ("Doctor & Video Messages") below the existing 2-column Settings page, plus a Doctor button on the Call tab.

3B · ALTERNATIVE

Left-Hand Tabbed Settings Sidebar

Splits Settings into vertical left tabs (General, Calls, Doctor, Media) for smaller screens.

Decision 4: Voice-Optional Smart To Do List
4A · CHOSEN

Browser Speech-to-Text + Local Date/Time Parser

Free, instant, zero API keys. Big 🎤 Mic button + "Who" pills (Gene, Peggy, Tom, Katie). Parses "by 10 on Tuesday" into Tue, Dec 1 · NLT 10:00 — Mail gifts (Gene).

4B · ALTERNATIVE

External LLM Parser

Handles arbitrary phrasing via Gemini/OpenAI API, but requires a paid/managed API key and network round-trip.

Decision 5: 5-Across Tall Call Page & 1-Row Landscape Meds
5A · CHOSEN

5-Column Call Grid (50% Taller, Name + Icon Only) + 1-Row Meds

Call page shows 5 buttons per row, 165px tall, no "Call" prefix, includes Doctor + extra Meet contacts. Landscape meds fit on 1 compact line per med.

5B · ALTERNATIVE

2-Line Med Rows + 3-Column Call Grid

Keeps dose on a separate line below med name (requires scrolling when 8 meds are due in one slot).
